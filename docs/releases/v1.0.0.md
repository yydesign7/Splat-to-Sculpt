# Splat to Sculpt v1.0.0

This is the first stable source release of Splat to Sculpt, a local-first node workflow for turning video or PLY input into processed 3D models and presentation videos.

## Highlights

- FFmpeg frame extraction and COLMAP sparse/dense reconstruction.
- True training and Fast Initializer Gaussian Splat routes.
- PLY/splat to mesh reconstruction with `geometry_graph_surface` layers capped at eight.
- Local Blender integration for cleanup, materials, lighting, and rotation renders.
- Local ComfyUI and Seedance integration for model-to-video generation.
- Reusable Assets library, thumbnails, workflow saving, Stop/Clear controls, and removable edges.
- Session-based temporary storage and automatic cleanup.

## Guided Setup

Requirements for the basic web interface are Node.js 20 or newer and pnpm 9 or newer.

### macOS

```bash
bash scripts/setup-macos.sh
pnpm dev
```

Install the Python processing packages as part of setup when reconstruction features are needed:

```bash
bash scripts/setup-macos.sh --install-python
```

### Windows

Run PowerShell from the extracted project directory:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup-windows.ps1
pnpm dev
```

Git for Windows is required because the existing development, build, and start commands use Bash scripts.

To install the Python processing packages:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup-windows.ps1 -InstallPython
```

### Manual Setup

```bash
pnpm install
pnpm python-deps
pnpm dev
```

Open <http://localhost:5001>.

## Optional Full-Workflow Tools

- FFmpeg for frame extraction.
- COLMAP for camera poses and sparse/dense reconstruction.
- Python 3.10-3.12 with the packages in `scripts/requirements-python.txt`.
- Blender for model cleanup, surface processing, thumbnails, and rotation renders.
- Nerfstudio for True training.
- ComfyUI with the bundled Seedance deployment pack for final video generation.

The setup scripts report missing optional tools without installing Blender, COLMAP, ComfyUI, Nerfstudio, or AI models automatically.

## Known Limitations

- Reconstruction quality still depends strongly on capture coverage, foreground separation, camera-pose registration, and point-cloud density.
- Thin structures can produce holes or unsupported faces during Poisson reconstruction.
- True training requires a compatible local Nerfstudio/CUDA environment.
- ComfyUI video generation requires the matching custom nodes, models, workflow preset, and API server.

See `README.md` or `README.zh-CN.md` for complete setup, workflow, storage, and troubleshooting information.
